Access Day

Access Day is a one-day conference about making the web easier to use for everyone. It's for people who build websites and want to learn the basics of web accessibility.

Event details

Date: Wednesday, December 8, 2027

Time: 9:00 AM to 5:00 PM

Location: Sample Convention Center, 123 Example Street, Faketown

Who it's for

This event is for students, developers, and designers who are new to web accessibility. You don't need any previous experience, just an interest in building websites that work for more people.

What you'll learn

  • What the Web Content Accessibility Guidelines (WCAG) and the POUR (Perceivable, Operable, Understandable, Robust) principles are
  • How people use assistive technologies, such as screen readers
  • How to test websites with accessibility tools, such as Lighthouse and WAVE
  • How to make accessible content with clear headings, alt text, form labels, and link text
  • When and how to use Accessible Rich Internet Applications (ARIA) roles and attributes

Access Day is a fictional event, created for learning purposes.
